# Diyar Market — Frontend Веб-Қосымшасы

Бул жойбар Google Stitch-те жаратылған UI дизайнлары ҳәм экранлары тийкарында таза қарақалпақ тилинде (кирилл әлипбесинде) толық жуўмақланған, мобил-бағдарланған заманаўый Frontend қосымшасы.

## 📁 Жойбар файллары:

1. **[index.html](index.html)** — **Басқы бет (Home Screen)**
   - Нөкис қаласы бойынша мәнзилди көрсетиў
   - Тез излеў ҳәм категориялар фильтри
   - 25-35 минутта тез жеткериў трекери
   - Акциялар ҳәм шегирмелер карусели (-20%)
   - Хит өнимлер карточкалары (баҳалар, сүўретлер ҳәм интерактив себетке қосыў түймелери)
   - Астыңғы навигация панели

2. **[catalog.html](catalog.html)** — **Каталог (Product Catalog)**
   - Категориялар чиплери (Мийўе & Овощ, Сүт өнимлери, Таза гөш, Нан)
   - Барлық өнимлер сеткасы ҳәм баҳалар
   - Излеў ҳәм себетке қосыў

3. **[product.html](product.html)** — **Өним толық мағлыўматы (Product Details)**
   - Алма (Golden Delicious) өниминиң жоқары сапалы сүўретлери
   - Салмақты таңлаў (0.5 кг, 1 кг, 2 кг, 3 кг)
   - Интерактив есаплағыш (+ / -) ҳәм баҳаның динамикалық өзгериўи
   - Өним сыпатламасы (Ферғана бағларынан, сақлаў мүддети, дәри-дәрмансыз)
   - Жабысыўшы (sticky) «Себетке қосыў» түймеси

4. **[cart.html](cart.html)** — **Себет (Shopping Cart)**
   - Себетке салынған өнимлерди басқарыў (+ / - арқалы көбейтиў, азайтыў ҳәм өшириў)
   - Динамикалық баҳа есаплаўы
   - Промо-код киритиў (`DIYARFRESH` — 15,000 сўм шегирме)
   - Бийпул жеткериў трекери
   - «Рәсмийлестириўге өтиў» түймеси

5. **[checkout.html](checkout.html)** — **Төлем ҳәм рәсмийлестириў (Checkout)**
   - 3-басқышлы прогресс индикаторы
   - Жеткериў мәнзили (Нөкис қаласы, 22-киши район) ҳәм курьерге ескертпе
   - Жеткериў ўақтын таңлаў (Бүгин 18:00 - 20:00, Кешки, Азанғы, Экспресс)
   - Төлем усыллары (Uzcard/Humo, Payme, Click, Қолма-қол)
   - «Буйыртпаны тастыйықлаў» түймеси

6. **[orders.html](orders.html)** — **Буйыртпалар ҳәм бақлаў (Order Tracking)**
   - Актив буйыртпа статусы (#DM-9824, «Жолда»)
   - 4-басқышлы реал ўақыт трекери (Қабылланды -> Жыйналды -> Курьер жолда -> Жеткерилди)
   - Нөкис көшелери картасы превьюси (Курьер аралығы: 1.2 км)
   - Курьер Бердақ Муратов (4.95 ⭐) пенен телефон/чат арқалы байланысыў
   - Буйыртпалар тарийхы таби

7. **[profile.html](profile.html)** — **Пайдаланыўшы профили (Profile & Settings)**
   - Пайдаланыўшы мағлыўматлары (Азамат Базарбаев)
   - Бонус ҳәм кэшбэк балансы
   - Сақланған мәнзил ҳәм бириктирилген карталар

## ⚡ Vercel-ге жүклеў:

Жойбарда Vercel ушын арнаўлы [vercel.json](vercel.json) конфигурациясы жаратылды.

### 1-усыл (1-клик арқалы автомат жүклеў):
Папкадағы **[deploy-vercel.bat](deploy-vercel.bat)** файлын еки мәрте басың.
Консоль терезеси ашылып, Vercel-ге автомат түрде жүклейди ҳәм сизге онлайн сайт силтемесин береди.

### 2-усыл (Vercel сайты арқалы Drag & Drop):
1. Браузерде **[https://vercel.com/new](https://vercel.com/new)** бетине кириң.
2. Компьютериңиздеги `diyar-market-frontend` папкасын браузерге сүйреп таслаң (Drag & Drop).
3. 10 секунд ишинде сизге пүткил дүнья бойынша көринетуғын `https://diyar-market.vercel.app` силтемеси бериледи!
